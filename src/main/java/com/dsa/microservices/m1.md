## 2️⃣ Microservice crashes due to traffic spike – How would you investigate?

### Step 1: Confirm Crash
- Service down or restarting?

### Step 2: Analyze Traffic
- Sudden spike in requests?
- Specific API overloaded?

### Step 3: Check Logs
- Exceptions (OOM, timeout, DB errors)

### Step 4: Resource Utilization
- CPU = 100%?
- Memory full?

### Step 5: Dependency Check
- DB slow → cascading failure
- External service delay

## 4️⃣ Spring Boot app throws DB connection errors – How to handle?

### Step 1: Check Logs
- Identify exact error:
  - Connection timeout
  - Too many connections

### Step 2: Verify DB Health
- Is DB running?
- Accepting connections?

### Step 3: Check Connection Pool
- HikariCP pool exhausted?

### Step 4: Check for Connection Leaks
- Long-running queries?
- Connections not closed?

### Step 5: Check DB Limits
- max_connections reached?

### Step 6: Immediate Fix
- Restart service
- Increase pool size
- Kill long queries

### Step 7: Long-Term Fix
- Optimize queries
- Add indexes
- Use caching

## 6️⃣ After Production Deployment Issue – First Step?

### Step 1: Assess Impact 🚨

- Rollback deployment if critical
- Switch traffic (blue-green)

### Step 3: Check What Changed
- Code changes?
- Config changes?
- DB migration?

### Step 4: Check Logs
- Errors after deployment

### Step 5: Monitor Metrics
- Error spike?
- Latency increase?
