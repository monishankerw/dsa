Java Try-with-Resources: Interview Questions and Answers

try-with-resources is a Java feature that automatically closes resources such as files, streams, and database connections after use.

1. What is try-with-resources? When was it introduced?

It is a try statement that automatically closes resources when the block finishes. It was introduced in Java 7. Resources must implement AutoCloseable (or Closeable).

Example
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) {
        try (BufferedReader reader =
                 new BufferedReader(new FileReader("data.txt"))) {
            System.out.println(reader.readLine());
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}

The reader is closed automatically after the try block, even if an exception occurs.

2. What are the benefits of try-with-resources?

  • Automatically closes resources.
  • Reduces boilerplate code compared with a manual finally block.
  • Helps prevent resource leaks.
  • Handles exceptions raised while closing resources.
  • Makes code easier to read and maintain.

3. What improvements were made to try-with-resources in Java 9?

Java 9 allows an effectively final variable that already exists to be used directly as a resource in the try-with-resources header. In Java 7 and 8, the resource generally had to be declared inside the parentheses.

Java 9+ example
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader reader =
            new BufferedReader(new FileReader("data.txt"));

        try (reader) {
            System.out.println(reader.readLine());
        }
    }
}
The variable must be final or effectively final: it must not be reassigned after initialization.

4. What exception-handling improvements came with Java 7?

  • Try-with-resources: automatically closes resources.
  • Multi-catch: catches multiple exception types in one catch block using |.
  • More precise rethrow: the compiler can infer more specific exception types when a caught exception is rethrown.
Multi-catch example
try {
    // code that may throw either exception
} catch (IllegalArgumentException | NullPointerException e) {
    System.out.println("Invalid input");
}

5. Why is resource cleanup important?

Resources such as file handles, streams, sockets, and database connections use operating-system or external-system resources. If they are not closed, the application can leak resources and eventually fail to open more files or connections.

Before Java 7, developers often closed resources in finally. With try-with-resources, automatic closing is usually simpler and safer.

6. Without try-with-resources vs. with try-with-resources

Without try-with-resources

Manual cleanup
BufferedReader reader = null;
try {
    reader = new BufferedReader(new FileReader("data.txt"));
    System.out.println(reader.readLine());
} catch (IOException e) {
    System.out.println("Read error");
} finally {
    if (reader != null) {
        try {
            reader.close();
        } catch (IOException e) {
            System.out.println("Close error");
        }
    }
}

With try-with-resources

Automatic cleanup
try (BufferedReader reader =
         new BufferedReader(new FileReader("data.txt"))) {
    System.out.println(reader.readLine());
} catch (IOException e) {
    System.out.println("File error");
}

The second version is shorter and automatically closes the reader.

7. What happens if both the try block and close() throw exceptions?

If the try block throws the main exception and closing the resource also throws an exception, the try-block exception is propagated. The close exception is recorded as a suppressed exception.

Example
class MyResource implements AutoCloseable {
    public void close() throws Exception {
        throw new Exception("Close failed");
    }
}

public class Main {
    public static void main(String[] args) {
        try (MyResource r = new MyResource()) {
            throw new Exception("Work failed");
        } catch (Exception e) {
            System.out.println(e.getMessage());
            System.out.println(e.getSuppressed()[0].getMessage());
        }
    }
}
Output
Work failed
Close failed

Practice questions

Q1. Does try-with-resources close a resource if an exception occurs?

Show answer

Yes. Java attempts to close the resource as the try-with-resources statement exits.

Q2. In what order are multiple resources closed?

Show answer

In reverse order of declaration.

Q3. Can a custom class be used in try-with-resources?

Show answer

Yes, if it implements AutoCloseable or Closeable and provides the required close() method.
